## Conventions

- Links use standard Markdown (`[text](path.md)`), not `[[wikilinks]]`, so they also work on GitHub. Type `[[` in Obsidian to autocomplete; it writes the Markdown link for you.
- Rename and move files **inside Obsidian** so links update automatically. Moving files in a file explorer or with `git mv` breaks links.
- Pasted images and files go in `attachments/`.
- Diagrams are draw.io SVGs exported with "Include a copy of my diagram", so they show as images everywhere and still open for editing in draw.io or the Obsidian **Diagrams** plugin. Embed them with `![alt](path.svg)`.
