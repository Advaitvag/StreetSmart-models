## How will we calculate confidence of a pothole detection?
This can be two part.
1. The model outputs a confidence score which can be used to tell how sure we are of a specific pothole. However, this alone may not be enough. 
2. Alongside model confidence, we will also use a score of repeats. i.e. how many times we've observed the same pothole. If we've seen the same pothole multiple times, we know it's real.

We will use a weighted equation of the model's confidence along with the repeat count. Something like:

 $Confidence_{total} = (w) * avg(Confidence_{model}) + (1 - w) * N_{repeats}$

> The weights themselves can be determined by testing to see what fits best. We could adopt something like linear regression with our dataset.

### How do we know if a pothole is one we've seen before?
This is probably gonna be tough. Our current runner ups are:
1. **Simple Coordinate Radius check**: If pothole within x feet of an existing detection, club them together, increment $N_{repeats}$ . Else, create new one.
2. **Visual Odometry**: Visual odometry is a method in robotics to give robots/machines/models object permanence-ish to track if it's one thing that you're seeing multiple times. This may be harder to implement, so we are holding on to it for now as an option in the future.

### How do we know it's the road we're looking at, and not a sidewalk?
This is a problem we can solve for later, but using CV techniques like color gradienting and meshing, we could differentiate the road with the sidewalk. This is a horizon task for now.
